# react-tic-tac-toe

## React Developer Tools

This app supports React Developer Tools in development. Install the browser
extension for [Chrome](https://chrome.google.com/webstore/detail/react-developer-tools/fmkadmapgofadopljbjfkapdkoienihi),
[Firefox](https://addons.mozilla.org/en-US/firefox/addon/react-devtools/), or
[Edge](https://microsoftedge.microsoft.com/addons/detail/react-developer-tools/gpphkfbcpidddadnkolkpfckpihlkkil), then:

1. Run `npm start` and open the app at [http://localhost:3001](http://localhost:3001).
2. Open the browser's Developer Tools.
3. Select the **Components** tab to inspect the React component tree, props, and state.

No additional package or app code is needed; the browser extension connects to
React automatically.
